Stanza Clock replaces Chrome’s new tab with an 8×8 or 16×16 letter matrix. The same face is in the toolbar popup. Settings live on a full-window options page with a live preview.

The three English 8×8 plates match the firmware in **[ESP-WordClock8x8](https://github.com/markusvankempen/ESP-WordClock8x8)** — an English 8×8 WS2812 word clock for ESP32-S3, ESP32, and ESP8266. Build the desk clock, then keep the same face on every new tab.

This page is the developer / homepage for the Chrome Web Store listing. Source will be published here after the store review.

## Privacy

- **Permission:** `storage` only — plate, colour, size, and effect settings
- **No network** — the system clock is the only time source
- **No accounts, no analytics**
